## Recent Updates (October 2026)

### Claude Haiku 5.5 in GitHub Copilot
GitHub Copilot now supports Claude Haiku 5.5 as an available model, giving developers access to a purpose-built model option alongside other available models. ([GitHub Changelog](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot))

### Local Sandboxing for GitHub Copilot
Local sandboxing for GitHub Copilot is now generally available in GitHub Copilot CLI, the GitHub Copilot app, and VS Code sessions using Agent Host. This provides a secure execution boundary for agentic workflows on developers' own machines. ([GitHub Changelog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available))

### Local Models Discovery in CLI
GitHub Copilot CLI version 1.0.94-0 makes it easier to discover and use local models from Ollama instances without leaving your existing workflow. ([GitHub Changelog](https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli))
